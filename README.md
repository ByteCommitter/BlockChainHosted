# BlockChainHosted
Development of a fully functional peer to peer blockchain system.

## Getting Started
Check the requirements once, after installation, open three terminals to simulate basic blockchain transactions.
Upto a 1000 users maybe simulated wiht the help of this blockchain, more maybe accomodated, with changing a little bit of code, obviously!

One the main terminal run:
npm run dev

on the other two terminals run:
npm run dev-peer


Maybe Use postman for ease, to run the API calls...
Great! Now you have now setup a peer to peer Blockchain system...
